# Gov_schema# 🏛️ Gov_schema

Gov_schema is a government schemes information application designed to help users discover and explore various government welfare schemes in one place. The goal is to make information about government benefits more accessible and easier to understand.

## 🚀 Features

- 📋 Browse government schemes
- 🔍 Search available schemes
- 📱 Simple and user-friendly interface
- ⚡ Fast and lightweight application

## 🛠️ Tech Stack

- Flutter (Dart)
- Python
- Supabase

## 📂 Project Structure

```
Gov_schema/
│── main.dart
│── main.py
│── supabase_setup.py
└── README.md
```

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/SiddharthBarkund/Gov_schema.git
```

Install the required dependencies.

Run the Flutter application:

```bash
flutter pub get
flutter run
```
